# 学术工作流程与接续约定

更新时间：2026-11-04T13:19:02+08:00。本约定按用户最新要求执行。

1. **确定轻量化的核心贡献。** 从具体问题、设计理由和已有证据中凝练值得发表的想法；允许合理组合已有机制，不要求每个部件原子首创，也不因已有阶段稿或固定实验完成而宣布科研目标完成。
2. **将水印上链部分与核心贡献形成完整系统链。** 围绕同一轻量上传对象，衔接完整性绑定、登记、聚合纳入和残差提交；系统设计与实际执行结果分别标明。
3. **完成优秀 CCF 会议论文的写作。** 以问题、缺口、方法、关键证据和贡献组织英文稿，语言准确、清晰、有说服力；避免研发流水账与反复自我削弱，保留会影响结论的关键对照。
4. **最后处理论文实验的数据复现可行性。** 留下支撑主张所需的数据、代码和实验说明；便携复现不是用户提出的默认要求，不以跨模型外审、完整工程迁移或复现包装作为前述工作的前置门槛。

好的想法、部分有效的数据验证和优秀的论文表述最重要。先确定问题与贡献，再安排能回答关键问题的必要验证；不以大型实验矩阵、审计数量或便携包装替代研究价值。

| 技能 | 适用任务 |
|---|---|
| hypothesis-generation、scientific-critical-thinking | 凝练问题、候选机制与贡献，按当前证据判断 |
| experiment-plan、analyze-results | 设计有信息量的小规模验证，读真实数据，区分训练种子与客户端 |
| anti-defensive-writing、research-writing-skill、paper-writer | 围绕有价值的贡献组织优秀 CCF 会议英文论文，避免工程汇报与反复自我削弱 |
| citation-management、venue-templates | 支撑关键归因与最终投稿格式，按实际需要使用 |
| experiment-audit | 需要时检查结果；后端不可用如实报告，不成为继续研究或写作的门槛 |

当前以统一状态页与 RUNNING_STATE.json 为准。旧 PLAN、报告和生成脚本保留阶段证据身份，不覆盖用户最新优先顺序，也不应直接用于重新关闭科研目标或恢复中文稿。中文论文已删除，后续只维护英文稿。

现有两任务、各三个固定训练种子的结果继续保留。已有官方 TEST 不用于后继调参；不恢复旧 STOP 路线或增加种子救结果。2027 年使用用户指定的2026年 svproc 模板的决定保持有效。科研目标仍在进行，不能以稿件编译通过宣布完成。
