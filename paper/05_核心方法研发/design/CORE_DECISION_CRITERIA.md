# 核心算法贡献：继续、转向和停止的判据

日期：2026-11-03。性质：方法设计的独立开发评议与后续可证伪实验建议，不是正式跨模型实验审计结论。

**当前判断：值得做一次有边界的验证；还不能将现有规则写成已经成立的“数据异构感知核心算法”。** 当前小幅闭环增益和确定性压缩器性质使它值得保留，但近邻已很直接，且真实 EF 状态出现与原机制预期相反的结果。应优先验证目标和参考是否有效，不应继续增加更多同类超参数、换名字或只追求更高历史投影。

本评议沿用 hypothesis-generation 的“观测—候选解释—区分性预测”流程及 experiment-audit 的证据边界。正式外部跨模型审计状态仍为 **REVIEW_UNAVAILABLE**；本地同模型子代理评议不替代该审计。没有修改冻结代码，没有启动训练，没有读取 confirmation 目录或 `official_test_final` 字段。

## 1. 冻结目前已经看到的观测

### 1.1 闭环开发结果存在小幅收益，独立重复仍不足

CPU 和 MPS 不能合并成两个独立训练种子：后端不同，且共享数据与随机种子的结果也不是两次独立抽样。20 轮、最后五轮、20 个客户端、2,000 张验证图像也都不是额外的独立方法重复。当前结果尚不足以估计跨划分/随机种子的波动。

### 1.2 真实 EF 的同状态反事实已经反驳“机制自动成立”

新读取的开发 probe：`work/method_followup/checkpoint_probes/cpu_topk20/result.json`，来源为 DONE 的 CPU Top-K-EF 20 轮状态，统一生成第 21 轮本地差分。所有方法共享模型、当前差分、参考、客户端权重和同一组残差；`official_test_evaluated=false`。它是一个状态的一步反事实，不是独立训练重复。

|---|---|---:|---:|---:|

| actual EF | prefix .99 | +0.003244 | -0.20 pp | -0.001607 |
| actual EF | random .9 | -0.000802 | +0.05 pp | +0.009363 |

| zero residual control | prefix .9 | +0.004936 | -0.05 pp | +0.034423 |

actual EF 下，历史参考与 `U=Σp_i(Δ_i+r_i)` 的余弦只有 0.05451；清零残差后为 0.37256。清零控制仍使用 EF 训练产生的模型和历史参考，因此只能隔离本次残差输入的作用，不能称为“从头无 EF 训练”的因果效果。

更关键的是：actual EF 下直接施加 dense(U) 的验证 loss 比 Top-K 高 0.062193。**积累残差后的完整 U 不是已知正确的当前下降目标。** 即使某选择器更接近 U，也不能据此推导学习效果更好。prefix .99 的本次结果正好提供“重建改善但验证损失恶化”的实例。

单个反例不能判定整个闭环方法无效，但它已经足以阻止把“保能 + 历史投影增加 ⇒ 异构聚合更好 ⇒ 损失更低”写成已证逻辑链。

## 2. 新颖性要面对的最直接近邻

现有检索材料中，最接近的不是普通 Top-K，而是：

- **RegTopK**，*Regularized Top-k: A Bayesian Framework for Gradient Sparsification*，IEEE TSP 2025，DOI `10.1109/TSP.2025.3624791`，开放稿 `arXiv:2501.05633`。它已用过去全局聚合结果影响当前 EF 上传选择，明确关心本地大值在聚合中的作用。项目中的 model-delta 适配必须如实标注，不冒充原始逐步 distributed SGD 完整复现。
- **FedSGC**，*Gradient-Congruity Guided Federated Sparse Training*，`arXiv:2405.01189`。它已利用全局模型差分符号指导稀疏训练；本项目当前只修改上传支持集，可作为区别，但“历史方向引导”本身不新。
- **L-GreCo**，`arXiv:2210.17357`，已有显式误差约束下的压缩配置分配。保能/失真约束本身不是新范式。
- **Rethinking gradient sparsification as total error minimization**，`arXiv:2108.00951`。它已经区分单轮固定 K 与跨训练总误差/总预算，采用 hard-threshold。若以后改成残差时序或总预算目标，它必须进入直接比较。
- **Overlap-weighted FL**，`arXiv:2408.14736`，DOI `10.1145/3673038.3673142`，已有坐标重叠造成聚合信号衰减的分析和坐标加权。不能把重叠频次直接当作“应否传输”的真值，也不能将改变聚合权重与当前保持 p_i 不变的选择器混为一谈。

证据入口：`work/literature_followup/FOLLOWUP_NEIGHBORS_BASELINES.md`、`ENERGY_ALIGNMENT_POSITIONING.md`、`LITERATURE_POSITIONING.md`；total-error 与 overlap 的公开原文提取分别为 `total_error.txt`、`overlap_weighted.txt`。检索不是系统综述；MultiGS/GRSGD 等全文仍有缺口。没有定位到完全相同公式，不能推出足够新颖。

当前可争取的贡献是一个**固定上传字节预算下、具有明确保护条件的具体选择规则，加上能区分近邻和竞争机制的稳定实证**。如果实验只剩约 0.4 pp 单种子优势、相似历史规则也达到相同效果，则不足以将其提升为独立核心贡献。

## 3. 把三个容易混淆的目标分开

令 `Q_i=TopK(u_i)`，候选上传为 `s_i`，固定所有客户端的 `u_i=Δ_i+r_i` 及权重 p_i。

### 3.1 本地重建：Top-K 已最优

对固定 K，`||u_i-Q_i||² ≤ ||u_i-s_i||²`。因此候选的保能界有意义，但不构成优于 Top-K 的本地重建证据。历史投影支配是选择目标本身带来的性质，也不是独立的学习效果观测。

### 3.2 聚合重建：必须核验交叉项是否真的抵消额外本地误差

定义 `e_i=u_i-s_i`，

\[
E=\sum_i p_ie_i,\quad
D=\sum_i p_i^2\|e_i\|^2,\quad
C=\|E\|^2-D.
\]

即 `||E||²=D+C`。无需计算所有客户端对，只需 O(MN) 计算 D 和 E，再用减法得到 C。

对同一组 u 和 p，候选相对 Top-K 有 `ΔD≥0`。所以聚合重建改善当且仅当

\[
\Delta C<-\Delta D.
\]

这比只展示“客户端之间更新方向不同”更有区分力。需要测的是**压缩误差的加权交叉项**，不是笼统的更新余弦、支持集重叠率或历史投影。

新 actual-EF probe 中，prefix .9 的 `ΔD≈+0.004948`，`ΔC≈-0.001580`，改善不足以抵消代价，净平方聚合误差 `≈+0.003367`。prefix .99 则 `ΔD≈+0.000391`，`ΔC≈-0.001903`，聚合重建确有改善，但验证 loss 仍更高。两种目标必须分别报告。

相对误差的分母必须在同一状态、所有方法间共享。U 范数很小时，同时报告未归一化误差和 U 范数，避免相对误差被小分母放大。不同方法各自训练轨迹的平均相对误差不能替代这个反事实分解。

### 3.3 当前下降：历史参考误差和曲率都可能破坏推断

设 `d=s-Q`，h 是当前希望保留的方向，g 是用于选择的历史参考，则由 Cauchy–Schwarz：

\[
\langle d,h\rangle
\ge\langle d,g\rangle-\|d\|\,\|h-g\|.
\]

聚合版本令 `d=Σp_i(s_i-Q_i)` 同样成立。历史投影增益只有超过参考误差项时，才保证相对 h 的投影不降低。g 和 h 必须使用可比较的单位/正尺度；仅用于方向诊断时可同时单位归一化，并报告归一化的约定。将 g 乘正标量不改变当前投影排序，但会改变误差项的尺度，不能暗中挑选有利尺度。

两种 oracle 要分开：

1. `h=U` 或 `h=Σp_iΔ_i`：诊断当前聚合重建或当前差分方向；不保证真实目标下降。
2. `h=-∇F_train(w+Σp_iQ_i)`：在 Top-K 更新后参考点，对候选的相对改动诊断当前一阶下降。F_train 可是预先冻结的训练来源 probe batch 目标，不能用最终 test 生成方向。若只在更新前 w 求梯度，得到的是该点一阶方向诊断，不能冒充两种完整更新结果的精确比较。

对于第二种 oracle，若相应 F 是 L-smooth，还有

\[
F(w_T+d)-F(w_T)
\le-\langle h,d\rangle+\tfrac L2\|d\|^2,
\quad w_T=w+\sum_i p_iQ_i.
\]

所以即使对当前负梯度投影更大，大改动也可能因曲率损失。这里是标准光滑性条件分析，不是新的联邦收敛定理。oracle 需要在诊断中集中访问客户端差分或计算全局训练目标梯度，不属于可免费部署的算法，也不能作为正式通信公平基线。

## 4. 最小可证伪对照：先用共享状态，不全部长训练

在已保存的共享张量上重做选择和一次验证，避免重复本地训练。先使用至少早/中/晚三个预先指定状态；尽可能同时包含 Top-K 与 prefix 各自轨迹状态，防止只研究一个压缩器生成的残差。状态不是独立训练重复，必须按来源运行归组。

所有选择器统一 K、原始 FP32 值、同一核心 C 与剩余名额 q；保留当前严格 signed 实现，允许负分数，不改成“只选正数然后补幅值”的旧描述。

| 候选解释 | 最少增加/保留的共同状态对照 | 区分性预测与失败信号 |
|---|---|---|
| H1：对当前异构抵消有用 | Top-K、prefix；分解 ΔD/ΔC；同数据总集和客户端计数的 skew 与 mixing=1；actual EF 与零残差 | 有效状态中 ΔC 应足够补偿 ΔD，并伴随验证损失受益。若只提高历史投影、这些指标不改善，则不支持该机制；不要求每一个状态都受益。 |
| H2：只是历史方向/动量偏好 | 真实 g、预先固定 EMA(g)、滞后 g_(t-ℓ) | 若简单 EMA/滞后规则达到同等任务收益，具体“异构抵消”解释不足。ℓ 在看结果前固定，不挑最有利滞后。 |
| H3：只是参考幅值挑选 | 同核心下对比 `u_j g_j`、`|u_j g_j|`、`u_j sign(g_j)` | abs-product 保留局部与全局绝对幅值但去掉方向一致性；sign-reference 去掉 g 的幅值。若效果相同，不能把完整 signed projection 视为必要机制。 |
| H4：坐标语义/噪声效应 | 保留每坐标 `|g_j|`，在同一参数张量内置换符号；同 q 的随机补位 | 真参考若稳定优于这些控制，才有其语义有效的证据。全局任意置换还改变层尺度关系，不能单独隔离方向作用。 |
| H5：旧残差与旧参考失配 | actual EF / zero residual；同时计算 g 对当前 `ΣpΔ` 与 `Σp(Δ+r)` 的余弦；加入 oracle h 反事实 | 若 oracle 明显改善而 stale g 不改善，支持先修参考；若连 oracle 都无任务收益，应质疑选择目标或步长，而非继续调历史系数。 |
| H6：样本权重造成的现象 | 同一 u 下，p=n_i/Σn 与 p=1/M 仅作为离线敏感性分析；加权/等权历史方向分别注明 | 若只在等权目标下有效，不能套用到样本加权全局目标。正式训练始终保持原定目标权重，不能悄悄改目标来获得提升。 |

计算预算紧时，先做 H1、H3、H5；H2/H4 都只需新增便宜的选择与验证，无需新训练。

注意两个控制问题：

- 现有 `sign50_ef`/`fixed50_ef` 用固定 50% 名额，与 prefix .9 的实际 q 不同，因此是有价值的竞争算法，但不是只改变参考语义的严格消融。新 probe 中 fixed50 的实际保能甚至约为 .831，而 prefix .9 约为 .967，这种差异不能归因于方向本身。
- 相同核心/q 不保证相同的最终能量。random .9 的能量通常更低。如果要细分“方向”和“多保了点能量”，增加一个**诊断性的能量分层随机补位**：在可行时匹配替换坐标能量区间，报告实际偏差；匹配失败就明确标记，不能假称完全等能。该控制只做机制识别，不冒充可部署新方法。

样本权重还有一个简单但重要的事实：对客户端 i 的所有坐标统一乘正数 p_i，不改变该客户端的 Top-K 排序。因此把 score 写成 `p_i*u_j*g_j` 不能单独构成新的“样本量感知选择”机制。p_i 真正影响的是共享参考、目标和跨客户端误差项。

## 5. 有上限的继续/停止规则

下面是**本项目的资源分配门槛，不是会议录用标准**。已有 pilot 已经被看过，因此这是在后续独立开发数据之前冻结的新决策计划，不能回写成原始预注册。所有配置、数据划分、主指标与失败/排除规则应在新结果产生前记录。不能读取确认 test 后再修改门槛。

### Gate A：是否值得继续闭环训练

1. 先完成上面的共同状态检查。至少应在某些预先抽取、具有真实 EF 的状态上，找到“真实参考相对幅值/符号控制带来任务损失收益”的证据；同时如实列出负状态。
2. 如果主要差别只存在于内在优化目标（历史投影/证书），或所有预定 actual-EF 状态上验证损失均不改善，停止升级 Lagrangian/扩大 τ 网格。允许保留 prefix 作为经验竞争基线，不据此宣布普遍无效。
3. 若不同轨迹/时期的结果相反，优先测参考误差与改动范数，而不是把有利时期选成主图。进入下一门只意味着机制尚值得验证。

### Gate B：是否有稳定的算法收益

固定一个候选、一个 τ 和一个主要稀疏率；以**同种子的最后五轮验证准确率均值差**为主指标，预定末轮 loss/准确率为次指标，不选择最好轮次。

- 第一批采用 3 组全新的“独立数据划分种子 + 训练种子”配对，每组运行 Top-K、候选和一个在开发集事先选定的直接强基线（优先 RegTopK model-delta 适配；FedProx+Top-K-EF 做必要的非IID优化对照）。方法间严格共享该组数据/初始化/批次种子。
- 可继续信号：候选对 Top-K 的平均差为正，且至少 2/3 组为正；不能只有一组大涨覆盖两组下降。若不满足，停止该候选作为主算法的开发。
- 实际价值目标暂定 **0.5 pp** 的同字节准确率收益。这是本项目在新数据前设定的工程目标，不是从当前单种子估出的统计噪声阈值，也不是普遍学术门槛。已有 +.41/.42 pp 只能说接近该目标，不能说已经超过随机波动。
- 若第一批方向一致但精度不足，最多增加一次到 **6 组独立配对**，不继续无限补种子直到显著。最终报告六个配对差、平均差及适合该实验单位的不确定性区间；小样本区间的假设必须注明。若方法含多个同一划分训练种子，按划分聚类或分层分析，不能把共享划分的运行全部当作独立样本。
- 核心贡献的 go：在最终固定批次中，平均差达到事先的实际目标、方向跨划分一致、区间不再兼容明显无收益，并且优于直接强基线或展示明确的准确率—真实开销 Pareto 优势。如果到预算上限仍不确定，结论是“目前不足以支持核心贡献”，而非选择最有利几组。

这里的 3/6 是有界筛选预算，不保证统计功效。若先验/开发配对方差显示 6 组仍无法区分目标效应，应在获取新的确认结果前调整研究精度或缩小主张，不能宣称六组天然足够。两个阶段的筛选不应包装成不经调整的确认性显著性检验；最终 test 保留一次独立报告用途。

### Gate C：是否能特别强调数据异构

使用相同全局训练图像集合、同客户端计数和固定训练协议的强 skew / mixing=1 配对。预先记录交互量

\[
I=(A-T)_{\rm skew}-(A-T)_{\rm nearIID}.
\]

若 I 在多数独立划分为正、强 skew 闭环确有稳定增益，而且同状态误差分解/参考对照与之相容，才有依据强调目标是异构稀疏聚合。若两种分布同样改善，可以写更一般的上传选择收益；若近 IID 更好，不能继续以“非IID特有优势”作为主标题。mixing=1 也不应称为数学上严格 IID。

再用第二任务或第二模型做一次冻结参数迁移，检查该规则是否只适配当前 CNN/CIFAR 划分。分类准确率、少数类表现和成本分别报告。单一任务、单一划分上的小幅收益不支持广泛适用或公平性主张。

### 成本和实现共同门槛

同 K 的 `64+8K` 字节是当前上传表示的核算模型，尚不是完整认证消息、链交易或真实网络测量。应单独报告 codec 时间、峰值工作内存/历史状态、下发参考取得方式；Lagrangian 的多次 Top-K 搜索不能按一次 Top-K 计算。新增 sketch、控制变量或重试都必须占用统一总成本预算。

τ=1 退化、残差守恒和确定性编码检查属于必要实现校验；它们不算学习贡献。后半部分链上验证可证字节/登记一致性，不能证明历史参考正确、客户端诚实训练或模型不会投毒。

## 6. 如果独立数据不确认收益，只保留一个有依据的新候选

**建议候选：带参考不确定性惩罚的有限改动选择。** 触发条件是：oracle 当前方向的共同状态实验有明确损失改善，而 stale-g 方案失败；或 Lagrangian 因支持集改动更大而明显更差。若 oracle 也无收益，不建议继续这一方向族。

仍令 Q 为同 K 的 Top-K，s 为保能可行的原值稀疏向量。考虑

\[
J(s)=\langle s-Q,\widehat g\rangle
-\xi\|s-Q\|,
\quad |\mathrm{supp}(s)|=K,
\quad \|s\|^2\ge\tau\|Q\|^2.
\]

包含 Q 本身（J=0），只从有限、事先固定的可行 swap/prefix/Lagrangian 候选中选择 J 最大者。因此无需宣称求解全局组合最优。若真参考误差满足 `||h-g_hat||≤ξ`，被选候选有 `⟨s-Q,h⟩≥J(s)≥0`。这是前述标准误差界的直接应用；若 ξ 只是经验估计，条件保证也只能写成条件保证。

实施前先做两个便宜筛选：

1. 用现有训练来源共享状态计算实际所需误差半径和 `历史增益/改动范数`，判断是否经常存在正稳健余量。若大多数状态只能回退 Q，停止，不为“更原则化”而另开长训练。
2. 用训练开发数据校准一个预先固定的经验半径/相对半径规则，再在未使用的开发划分验证它能否识别失配；不能把 oracle ξ 当作部署时已知，也不能用最终 test 校准。历史差分波动不是 `||h-g||` 的确定上界。

成本：已有有限候选集合时，每个候选增加 O(K) 或 O(N) 的点积/范数及能量检查，复杂度为 `O(J*selection_cost)`，需实测；保持同 K 原值上传，不新增上行。使用全模型历史参考仍有 O(N) 状态成本。若需要新的参考通信，另计字节。

这只是**更保守地决定何时值得偏离 Top-K**，可能退化成普通 Top-K，也可能只是现有鲁棒优化/信赖域思想的应用。尚未完成针对该目标的优先权核查，不能宣布新范式；它必须在直接强基线和冻结任务实验上赢得核心贡献地位。

不同时新增熵门控、更多预测器、年龄权重、设备预算和多级压缩。若转向跨轮 residual/总通信预算，应先以 total-error hard-threshold 作为已有基线，而不是把现有时序最优化重新命名为原创候选。

## 7. 给主文写作的当前口径

目前可以写：提出并实现固定 K 的保能方向选择器；给出单步保能/投影性质；在一个开发划分观察到小幅闭环收益；用共同状态实验识别历史参考与 EF 失配的限制。

目前不能写：已经解决数据异构、首次利用全局方向、在同 K 下重建普遍优于 Top-K、Lagrangian 精确解原离散问题、历史投影保证非IID训练下降、完整鲁棒性或广泛优越性。

下一步最有信息量的行动是完成有限的共同状态反证与新独立划分配对。若失败，保留全部负结果并调整论文贡献；链上流程已经完善，也不能替前半部分补出尚不存在的算法证据。
