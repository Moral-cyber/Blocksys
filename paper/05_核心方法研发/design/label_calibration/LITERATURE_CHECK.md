# FedLC 原文核查（2026-11-04；未训练）

结论：适合作为“本地 label skew 训练偏差”的低开销候选，但本次未确认作者仓库；零计数规则及 τ 默认值均不能冒称官方。核查仅含一篇 primary，未借第三方复现补规则。[原文](https://proceedings.mlr.press/v162/zhang22p/zhang22p.pdf)

**公式与复现边界。** 对客户端 c 的本地类别计数 n_{c,k}，定义 d_k=τn_{c,k}^{−1/4}。原文第5页 Eq.(6)：Δ(y,i)=τ(n_y^{−1/4}−n_i^{−1/4})。Eq.(7) 的印刷式明确是

L_print=−log[exp(z_y−d_y)/Σ_{i≠y}exp(z_i−d_i)]。

但第17页附录 C 的概率分母为 Σ_{k=1}^Kexp(z_k−d_k)，对应通常实现的 L_CE=CE(z−d,y)。两者有实质差别：L_CE=log(1+exp(L_print))，L_print 可为负，τ=0 也不等于普通 CE；不能悄悄把分母改成全类后称逐字复现。采用 L_CE 应明示这是遵循附录概率及“calibrated CE”描述的实现选择。

**零类别与参数。** 第3页定义缺失类 n_s=0，正文/附录未给 ε、floor、伪计数或实际代码规则。直接逆幂在零处未定义；按极限解释 d_s→∞，其校准 softmax 概率与梯度趋零，不能当作已证实的作者实现。τ 仅称超参数，无可核验的数值或搜索区间。第6页默认20客户端、batch128、SGD lr0.01、无weight decay、5 seeds；这些不同于当前 batch64/lr0.03，论文收益不可直接迁移。count 换为频率也会改变尺度，不能沿用同一 τ 而不说明。

**影响范围。** 校准加在最后分类层输出、softmax 之前，改变各类 logit 梯度，反传会同时改变分类头和特征提取器，并非只修末层。少类 d 更大，训练中须提高其原始 logit 才能补足 margin；它不会凭空提供缺失类正样本。第14页 Algorithm 1 从同一全局 w 出发，用校准损失更新本地参数并返回 w；目标仍是单一 global model。推理按第4页 argmax z，不需要客户端标签先验或个性化头。

**与 TopK+EF 的条件及隔离建议（本次建议，非原文结论）。** 仅替换本地训练损失；令 Δ=w_local−w_global，u=Δ+e，q=TopK_5%(u)，e←u−q，再以原权重聚合 q。所有参数沿用同一压缩预算，不额外豁免分类头；本地保存 O(K) 计数/偏置，每batch多一次 O(BK) 减法，通信无需增加标签直方图。

实施前固定并披露有限计数规则，例如 ñ=max(n,1)，以及采用全类 CE；这些是自定实现规则，不能称官方。τ=0 直接调用原 CE。最小隔离为 dense/TopK+EF × CE/校准CE 四格，同 seed、切分、学习率、轮次、聚合与字节口径；关注校准对 dense 的收益及交互项“TopK校准收益−dense校准收益”。若只改善 dense/hetero，可支持修复 label skew，不能据此声称解决异构特有压缩损失，更不能把 FedLC 已知收益当自己的创新。原文没有验证 TopK+EF 组合，也不保证当前设置正收益。
