\section{Introduction}

Federated learning trains a shared predictor from distributed client data through repeated local updates and aggregation \cite{mcmahan2017fedavg}. When label distributions differ across clients, a shared predictor and a client-specific probability predictor address different objectives. A class can be common locally even when it has little influence on another client's updates. Consequently, a model's classification accuracy alone does not describe the quality of its probabilities for an individual client. This distinction matters when communication constraints require compressed updates while local prediction remains personalized.

Several established ideas address parts of this setting. Federated optimization methods study heterogeneous local objectives \cite{li2020fedprox,karimireddy2020scaffold,wang2020fednova}; personalization layers provide another direction \cite{arivazhagan2019fedper}. Label-aware training includes logit adjustment, Balanced Softmax, and FedLC \cite{menon2021logitadjust,ren2020balanced,zhang2022fedlc}. FedRoD links generic training to persistent personalized prediction \cite{chen2022fedrod}. Post-training temperature and vector scaling instead act on an already learned score function \cite{guo2017calibration,alexandari2020labelshift}. These approaches motivate a concrete comparison: how much of local predictive quality comes from the training loss, the local label prior, and the flexibility of the final score transformation?

We examine whether a local label-prior anchor can improve personalized negative log likelihood (NLL) after low-bit federated training, while preserving accuracy relative to fixed controls. The object is a shared final network followed by a small client-specific transformation, rather than a separately trained client backbone. The primary comparison retains the same affine capacity and changes only the bias anchor. This formulation treats empirical label counts as regularization information; it does not assume that a prior correction exactly recovers an unknown client posterior.

Three requirements shape the study. First, probability quality and classification accuracy must be assessed separately: optimizing log loss can change both confidence and class decisions. Second, the communication comparison must use serialized payloads, including scales and metadata, rather than nominal bitwidth alone. Quantization, sparsification, and error-feedback methods provide relevant communication mechanisms \cite{alistarh2017qsgd,stich2018sparsified,karimireddy2019errorfeedback}. Third, retransmission should not silently change which residual corresponds to an incorporated update. That consistency question concerns the upload lifecycle and is distinct from predictive accuracy or the honesty of a client's update.

The resulting procedure combines an explicitly defined FedLC-inspired local loss, uniform three-bit block quantization with FP32 error feedback, and TRAIN-only prior-regularized vector adaptation. After the shared network is frozen, each client fits class-specific scales and centered biases using saved local logits, a fixed quadratic penalty, and a smoothed count-derived bias anchor. We compare this transformation with deleted-anchor vector scaling, bias-only adaptation, scalar-temperature controls, matched last-layer adaptation, and separate compression and persistent-personalization references. Client-macro NLL is the primary endpoint, with accuracy preservation and independently reported Brier and calibration-error measures. CIFAR-10 and FashionMNIST provide the two task settings \cite{krizhevsky2009tiny,xiao2017fashion}.

The contribution is a controlled assessment of this combination, together with explicit implementation and evidence boundaries. The predictive comparison separates prior anchoring from affine capacity and training choices. The resource accounting connects decoded upload bytes to deployment state, error-feedback storage, forward passes, and fitting caches. A separate durable local protocol binds complete payloads to their training context and commits client residuals only after incorporation. Its authentication uses HMAC \cite{rfc2104}; its evaluation establishes a local transaction and recovery scope rather than a deployed blockchain system. These contributions concern the quality, cost, and state consistency of an integrated procedure, without claiming that vector scaling, prior regularization, quantization, error feedback, or Newton optimization is individually new.

\section{Related Work}

\paragraph{Heterogeneity and personalization.}
FedAvg provides the federated averaging setting \cite{mcmahan2017fedavg}. FedProx, SCAFFOLD, and FedNova address heterogeneous optimization through different formulations \cite{li2020fedprox,karimireddy2020scaffold,wang2020fednova}, while FedPer studies personalization layers \cite{arivazhagan2019fedper}. Our central question concerns the final client's probability scores under fixed shared-model training. The FedRoD-linear reference additionally tests persistent local residual prediction alongside a generic branch \cite{chen2022fedrod}. We disclose its global-generic-plus-local-residual endpoint choice and use an explicit implementation variant, rather than asserting an exact official-code reproduction.

\paragraph{Class counts and score calibration.}
Logit adjustment and Balanced Softmax establish class-frequency-aware constructions \cite{menon2021logitadjust,ren2020balanced}. FedLC motivates count-dependent local logit margins \cite{zhang2022fedlc}; our count floor, unit multiplier, and all-class cross-entropy are specified implementation choices. Temperature scaling, vector scaling, and bias-corrected temperature scaling are existing calibration families \cite{guo2017calibration,alexandari2020labelshift}. Our controlled variable is the local TRAIN-prior anchor in a fixed regularized score family. Comparison with a scalar-scale, same-prior BCTS control is necessary before attributing any effect specifically to class-dependent scales.

\paragraph{Communication and upload integrity.}
QSGD concerns quantization and encoding \cite{alistarh2017qsgd}; sparsified SGD with memory and error feedback address compressed updates \cite{stich2018sparsified,karimireddy2019errorfeedback}. We use these established directions as context for exact byte-level compression references, without transferring their theoretical guarantees to this federated setting. Blockchained on-device federated learning studies a different system architecture \cite{kim2020blockfl}. Our SQLite/HMAC simulation supplies neither consensus nor a public ledger. Shared-secret payload authentication \cite{rfc2104} protects the recorded context and bytes within the stated trust model; it does not embed a model watermark or establish update correctness.
