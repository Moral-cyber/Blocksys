# 时变聚合权重与 EF 记账：有限验证

本轮只用 NumPy、冻结合成 delta 和抽样序列验证代数，没有模型、真实数据、训练或测试结果。实际运行脚本为 `diagnose.py`，全部原始输入和逐轮数值保存在 `diagnose.json`。

## 标准本地残差的正确恒等式

令客户端 i 的第 k 次参与时权重为 a_(i,k)，本地 EF 满足

\[
r_{i,k}=\delta_{i,k}+r_{i,k-1}-s_{i,k}.
\]

初始残差为零时，服务器累计未压缩贡献与累计上传贡献之差为

\[
D_T^{local}=\sum_i\sum_{k=1}^{m_i} a_{i,k}(\delta_{i,k}-s_{i,k})
=\sum_i a_{i,m_i}r_{i,m_i}
+\sum_i\sum_{k=1}^{m_i-1}(a_{i,k}-a_{i,k+1})r_{i,k}.
\]

所以仅用“最后一次参与权重 × 最终本地残差”不能一般表示服务器累计压缩债务；缺少的是中途权重重估残差的项。未参与客户端状态不变，但它下一次参与时的权重可变。

全局贡献单位的版本为

\[
v_{i,k}=a_{i,k}\delta_{i,k}+e_{i,k-1},\quad
q_{i,k}=\operatorname{TopK}(v_{i,k}),\quad
e_{i,k}=v_{i,k}-q_{i,k}.
\]

服务器直接求和 q，不能再次乘 a。其零初始状态给出

\[
D_T^{global}=\sum_i e_{i,m_i}.
\]

这也等价于在客户端每次激活时，把旧本地尺度残差按 a_prev/a_new 重新标度，再做普通 EF，并上传 a_new*s；只是记账单位的不同表达。该等价本身不构成算法新颖性。

当每个客户端参与时的 a_i 恒定且为正，TopK 的正尺度齐次性给出 e_i=a_i*r_i、q_i=a_i*s_i，两方法在精确算术下逐轮等价。等样本量+固定参与数，以及异样本量+全参与，均属于此情况。

## 手算例的范围修正

外定两客户端权重先 (.1,.9)、后 (1/91,90/91)；只有客户端0首轮 delta=(1,.9)，次轮为零，K=1。普通 EF 首轮发送 (1,0)，次轮发送 (0,.9)，残差最终全零，但服务器累计差为

\[
(0,.9\times(.1-1/91))=(0,.08010989010989011).
\]

全局单位版本首轮上传 (.1,0)，保留 (0,.09)；次轮上传 (0,.09)，最终债务和残差均零。

**只有两个固定 n 客户端，且按 active 样本量归一化时，不能产生 .1→1/91。** 因此它只作外定权重的代数例。另用固定 n=(1,9,90)、两人参与集合 (0,1)→(0,2) 得到严格合法的同一权重变化，其他客户端 delta 为零，数值完全复现。该手选序列可由 uniform size-two sampling 产生，但不是抽样统计推断。

## 20 客户端有限数值结果

固定异构样本量，每轮 uniform 无放回选5/20，共60轮；预先生成同一 delta 流供两方法使用。P=13、K=3，全部 float64。等样本量对照使用同一抽样与 delta；全参与对照使用同一 delta。

| 检查 | 原始数值 |
|---|---:|
| 变权时，仅最终加权本地残差的恒等式缺口范数 | 5.158357840610304 |
| 标准 EF 加入权重变化项后的最大误差 | 9.43689570931383e-15 |
| 全局单位 EF 望远镜恒等式最大误差 | 6.994405055138486e-15 |
| 等 n、同一固定人数抽样，两方法逐轮差最大值 | 2.220446049250313e-16 |
| 异 n、恒定全参与，两方法逐轮差最大值 | 2.220446049250313e-16 |
| 未参与客户端状态变化 | 0 |

这个结果证明/验证的是**代数记账差异**。它没有证明全局单位版本的最终债务范数总是更小，也没有证明标准 EF 的既有收敛分析失效，更没有证明样本异构或标签异构下的准确率收益。

服务器要在压缩前让每个 active 客户端知道自己的 a_i；若客户端已有 n_i，只需知道 active 总样本量。是否需要额外广播，应按现有参与选择协议计入。该问题涉及统计权重和样本量异构，不涉及物理带宽。

本轮两方法共享与模型轨迹无关的合成 delta，这是有意隔离代数的 fixture；真实闭环训练中 delta 会随模型分叉。变权采样自身也可能改变目标或带来 ratio-estimator 偏差，EF 记账不会自动解决该问题。新颖性和学习价值均尚未判定。
