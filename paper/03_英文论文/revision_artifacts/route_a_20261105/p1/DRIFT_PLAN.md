# Approved development-only stale-prior drift diagnostic

Parent approval received before execution. This does not estimate new priors or fit a predictor. It freezes each original seed's shared model logits and its prior-centered/zero-centered FP32 states. Exactly the saved development holdout sample universe is reused, once per scenario; original images and official TEST remain unopened.

For each task, concatenate the twenty clients' saved holdout examples, sorted by original holdout identifier, and verify that ids/labels and original client membership are identical across the three training seeds. A fixed PCG64 seed20261105 supplies ten classwise target allocations q_c~Dirichlet(alpha=.1 over20 clients) and a fixed movement order within each class. For rho in{0,.25,.5,.75,1}, move the first floor(rho*N_c) ids in each class's order; assign moved examples to target clients using largest-remainder q_c quotas and client-index tie breaking. Every other example retains its original client. Rho0 preserves the original membership exactly, with no resampling. All three model seeds share exactly the same membership for each rho.

A target is generated using labels/ids alone, before any prediction metric is calculated. If any client is empty at any declared rho, redraw the target using the same ongoing PRNG stream, until all clients are nonempty, with a cap of10000 draws. All attempts and the label-only reason are recorded. No target or rho is selected by performance.

For every model seed/scenario, apply the frozen original destination-client prior/zero state to that seed's pooled shared logits and score client-macro and sample-weighted NLL/accuracy. Also record the mean destination-client total-variation distance between original holdout empirical class priors and the new empirical priors. Rho0 is checked against the saved development summaries to1e-12. The inference says how stale local predictors behave under controlled holdout reallocation; it cannot establish successful adaptation to drift or deployment behavior. No new training seeds, CNN calls, fitting, source edits or existing result edits occur.
